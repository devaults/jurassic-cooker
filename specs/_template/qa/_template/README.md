### 0.1 运行环境（跑前端用例前必读）

> 需要操作前端（E2E / 手测）时，执行者先读本节拿到访问地址与登录方式；
> **需要登录的，由人接管登录**——执行到登录页即暂停，请人登录后继续。未填 = 前端用例无法开跑。
> **安全**：本节**只登记测试环境地址**，**不记录任何凭据**（账号 / 密码一律不入库）；**切勿填写正式（生产）环境信息**。
