## 3. 全局自检

> **开工前**逐项核对；不通过则不开工。

- [ ] 上游 `design-contract.md` v1 已签字（**同步闸口**）
- [ ] 上游版本号已填进 §0 「上游需求 / 契约」

> **完工前**逐项核对；不通过则不签字。

- [ ] 所有 T-NN 卡片内自检通过（单任务自检在卡片内）
- [ ] 全量任务状态 = `✅` 或明确标注 `❌` 与原因
- [ ] 改动文件清单与 PR 链接已记录
- [ ] `mvn verify` / 关联测试全过
- [ ] Sonar 通过（用 MCP）
- [ ] OpenAPI 实现与 `design-contract.md` v1 100% 对齐
