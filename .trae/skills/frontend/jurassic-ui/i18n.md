# 多语言（Jurassic UI 2.x）

v2.0.1 起，`locale` **已合并** Ant Design Vue 语言包 + Jurassic 业务文案。分页、日期、空状态等组件文案，以及 `common.*` 业务键，都从这一份对象读。

## 使用合并语言包

```ts
import { locale } from 'jurassic-ui'

locale.zh_CN  // 中文：AntD Locale + 约 2700 条业务键
locale.en_US  // 英文：同上
```

类型：`Locale & Record<string, string>`（AntD 嵌套字段 + 扁平 `common.*` 字符串）。

根组件：

```vue
<script setup lang="ts">
import { JuraConfigProvider, juraTheme, locale } from 'jurassic-ui'
</script>

<template>
  <jura-config-provider :theme="juraTheme" :locale="locale.zh_CN">
    <router-view />
  </jura-config-provider>
</template>
```

## 运行时切换中/英

用当前语言对象驱动 ConfigProvider（不要只改 `locale.locale` 字符串）：

```vue
<script setup lang="ts">
import { computed, ref } from 'vue'
import { JuraConfigProvider, juraTheme, locale } from 'jurassic-ui'

const lang = ref<'zh_CN' | 'en_US'>('zh_CN')
const antdLocale = computed(() => locale[lang.value])
const t = (key: string) => antdLocale.value[key] ?? key
</script>

<template>
  <jura-config-provider :theme="juraTheme" :locale="antdLocale">
    <jura-radio-group v-model:value="lang">
      <jura-radio-button value="zh_CN">中文</jura-radio-button>
      <jura-radio-button value="en_US">English</jura-radio-button>
    </jura-radio-group>
    <jura-button type="primary">{{ t('common.form.submit') }}</jura-button>
    <jura-pagination :total="50" show-size-changer />
  </jura-config-provider>
</template>
```

切换后：Pagination / DatePicker / Empty / Modal 等 AntD 文案会变；业务按钮文案用 `t('common.*')` 才会变。

## 业务文案键

扁平 key，直接 `locale.zh_CN['common.form.submit']`。库**没有**内置 vue-i18n；需要插值/复数时再在项目里接 vue-i18n，把同一份 `common.*` 当消息源。

常用通用键（写页面优先用这些，不要硬编码「提交」「取消」）：

| Key | 中文 |
| --- | --- |
| `common.form.submit` | 提交 |
| `common.form.reset` | 重置 |
| `common.form.save` | 保存 |
| `common.form.add` | 添加 |
| `common.form.confirm` | 确认 |
| `common.form.operation` | 操作 |
| `common.button.confirm` | 确定 |
| `common.button.cancel` | 取消 |
| `common.button.delete` | 删除 |
| `common.button.search` | 查询 |
| `common.button.add` | 新增 |
| `common.button.edit` | 编辑 |
| `common.button.view` | 查看 |
| `common.button.import` / `common.button.export` | 导入 / 导出 |
| `common.nav.home` | 首页 |
| `common.nav.logout` | 退出登录 |
| `common.success.message` | 操作成功 |
| `common.failure.message` | 操作失败 |
| `common.loading.text` | 加载中 |
| `common.no_data.text` | 无数据 |
| `common.please_enter` | 请输入 |
| `common.please_select` | 请选择 |
| `common.required` | 必填 |
| `common.yes` / `common.no` | 是 / 否 |

OIO 业务键前缀为 **`common.oio.*`**（两千余条）。页面属于 OIO 域时先查该前缀，不要再造一套中文。完整表在包内 `jurassic-ui` 的 locale 实现（源码 `es/locale/lang/zh_CN.es.js` / `en_US.es.js`）。

## 和 vue-i18n 共存

ConfigProvider 的 `locale` **只**影响 Jurassic/AntD 组件内部文案。应用路由标题、自定义段落仍用项目 i18n。建议：

1. AntD/Jura 组件：始终喂 `locale.zh_CN` 或 `locale.en_US`。
2. 业务文案：能复用 `common.*` 的不要新写；缺 key 时在**项目** locale 里补，不要改 node_modules。
3. 日期组件时区/周起始日随 AntD locale，不要再引一份 `dayjs` locale 却忘了换 ConfigProvider。

## 不要做的事

- 不要 `import zhCN from 'ant-design-vue/es/locale/zh_CN'` 作为唯一语言包（缺业务键，且与官方 examples 的合并包不一致）。
- 不要 `app.use(JuraUI, { locale: zhCN })`，插件不处理该参数。
- 不要假设存在 `locale.zh-CN`（连字符）或 `locale.cn`；导出键是 `zh_CN` / `en_US`。
