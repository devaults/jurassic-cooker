# Tool Discipline：工具与文件操作

## 1. 先读后改（强制）

- 编辑前**必须读目标文件最新内容**，禁止凭记忆编辑
- 改函数/组件读完整代码块；只改一行也要看上下文
- 编辑后通过输出确认修改正确

## 2. 搜索工具选择

| 场景 | 工具 |
|------|------|
| 已知文件名/路径 | Read / Glob |
| 文件名模式（`*.vue`） | Glob |
| 精确关键词/正则 | Grep |
| 自然语言描述、跨文件语义搜索 | 语义搜索（SearchCodebase） |
| 列目录 | LS |

## 3. 并行与串行

- 独立的信息获取**并行**（同时读多个文件、搜多个关键词），不超过 6 个
- 有依赖的**串行**（先搜路径，再读文件）

## 4. 失败处理

- 相同工具、相同参数失败最多重试 1 次，第 2 次必须换方法
- Read 失败 → Glob/Grep 确认路径
- Grep 无结果 → 换关键词或改语义搜索
- Edit 失败 → 重新 Read，确认 `old_string` 唯一且精确

## 5. 文件与命令

- 优先编辑已有文件，非必要不新建
- 长时命令（dev server 等）后台运行并记下 job id，不要阻塞等待
- MCP：先读目标工具的 schema 再调用，禁止凭记忆传参
