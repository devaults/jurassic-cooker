# Context Hygiene：上下文窗口卫生

> **本文件是"上下文管理与长任务记忆"的硬约束，也是"关键决策持久化"的唯一归属**。
> 内在准则见 [`self-harness.md`](./self-harness.md)；协作纪律与会话边界见 [`context-collaboration.md`](./context-collaboration.md)。

---

## 1. 上下文来源（先认账）

| 来源 | 占比（典型） | 控制权 |
|---|---|---|
| 规则注入（`rules/`） | 5-15% | 框架侧（本文管） |
| 技能触发（`skills/`） | 5-20% | 框架侧（本文管） |
| 工具调用历史（Read / Edit / Grep…） | 30-50% | **最大头**，靠工具选择 |
| 对话轮次 | 10-20% | 用户主导 |

> 可优化空间集中在规则/技能/工具三块；对话本身压不动。

---

## 2. 加载阈值（硬）

| 项 | 阈值 | 越界怎么办 |
|---|---|---|
| 单个规则 `*.md` | ≤ 200 行 | 拆主题 / 抽子文件 / 改 skills |
| 单个技能 `SKILL.md` | ≤ 400 行 | 拆步骤文件 / 抽 `components.md` 等附档 |
| 同主题重复声明 | **0 处**（绝对） | 见 `RULE.md` §二「约束归属」 |

**过载信号**（出现即提醒开新会话）：AI 漏掉之前提过的约束 / 重复问同一件事 / 输出质量下降。

---

## 3. 决策持久化（铁律）

> **所有关键决策 + 数字 + 选型必须写进文件，不依赖 AI 记忆。**

| 写什么 | 写哪 |
|---|---|
| 关键决策（选 A 不选 B） | `specs/domains/<domain>/<feature>/<stage>.md` 的"决策记录"段 |
| 数字 / 阈值 | `config.yaml` 或 `.env.example` |
| 跳过的场景 | `specs/domains/<domain>/<feature>/requirements.md` 的"不做"清单 |
| TODO / 残留风险 | `specs/domains/<domain>/<feature>/qa/README.md` 或独立 issue |

**格式**：

```markdown
[决策] 选 X 不选 Y，理由 Z
[约束] 阈值是 10MB，配置在 config.yaml L20
[不做] 场景 A，明确放弃，理由 B
[待定] 场景 C，需等 D 决定
```

## 4. 阶段摘要存档

> 长任务每完成一个阶段，**强制写一段摘要**——让"开新会话也能立刻接上"。

**何时**：阶段产物签字 / 单轮 >30 轮 / 跨天继续 / 准备开新会话接手。

**模板（≤ 30 行）**：

```markdown
# 阶段摘要：<阶段名> @<日期>

## 现状
- 已完成 / 进行中 / 待办：各一句话

## 关键决策
- [决策] 选 A 理由 B｜[不做] 场景 C 理由 D｜[阈值] 10MB（config.yaml L20）

## 文件清单（改 / 建 / 删）
- 改：path/to/x.ts（目的）｜建：path/to/y.vue（目的）｜删：path/to/z.ts（引用已查）

## 残留风险
- R1：<未覆盖的边界>

## 下一步
1. <下一个阶段的第 1 步>
```

**放哪**：阶段交付物自身的"变更摘要"，或 `specs/domains/<domain>/<feature>/.stage-summary.md`。

## 5. 单轮工具调用卫生

> 每轮对话的工具调用是上下文最大头。

| 限制 | 阈值 | 越界怎么办 |
|---|---|---|
| 单轮 Read / Grep 调用数 | ≤ 5 | 派 subagent 并行（见 `parallel-agents.md`） |
| 单次 Read 大文件 | 限流读取（offset/limit） | 分段读，不一次读全 |
| 重复读同一文件 | **0 次** | 需确认用 `Grep` 关键词而非 `Read` 全文 |

**上下文杀手**：`Read` 整个千行文件 / `cat` 大 JSON / 每改一行回读 / 把整份 issue 粘进对话 → 分别用"Grep + 限定行 / 解析后取字段 / 改完一次回读 / 写进 specs 引用"替代。

---

## 6. 跨会话承接与满载应对

**开新会话前**：① 写阶段摘要（§4）② 确认关键决策已存档（§3）③ 写"承接包"（≤20 行：接续前情链接 + 已读版本 + 关键决策 + 下一步 + 不要做）。
**开新会话后**：第一轮先复述承接包让用户确认，用户说"开始"再动手。

| 满载阶段 | 动作 |
|---|---|
| 预警（剩 30%） | 主动提醒；**现在**写摘要 |
| 临界（剩 10%） | 立即写摘要 + 提示用户开新会话 |
| 已满 | 只做"写摘要 + 提示开新会话"，不再接新任务 |

> **不要硬撑**——满了之后 AI 行为会随机漂移，比从头做更危险。
> **一句话**：关键决策写文件不写对话；阶段完成写摘要；长任务拆会话；满了只写摘要。
