# Context & Collaboration：协作与上下文

> **强制**：本文件是"与用户协作"主题的唯一归属（协作纪律、会话边界、状态追踪、分歧、验收）。
> 内在准则（自省 / 计划先行 / 事后反思）见 [`self-harness.md`](./self-harness.md)；
> 关键决策持久化与上下文过载应对见 [`context-hygiene.md`](./context-hygiene.md)，本文件不重复。

## 1. 协作纪律（强制）

- 遇到阻塞**立即告知**；长任务定期同步进度
- 发现代码潜在问题 → **告知，但不擅自修复**
- 需要决策时给出选项让用户选择，而不是默默替他决定

## 2. 会话边界

- 一个会话只处理**一个逻辑闭环任务**（一次改动 + 对应验证 + 失败项修复完成）
- 轮次过多（>20 轮）或话题明显切换时，**主动提醒**用户开新会话
- 出现上下文过载信号（漏约束 / 重复讨论 / 频繁回顾早期对话）→ 同上，提醒开新会话

## 3. 跨轮次状态追踪

- 持续标记任务状态：已完成 / 进行中 / 待处理
- 记录本轮已改文件，不重复改已完成部分
- 新信息出现时评估是否需要修正之前的决策
- 关键决策**写文件**、不依赖模型记忆 → 见 [`context-hygiene.md`](./context-hygiene.md) §3

## 4. 分歧处理

- 多方案时用户选定后不再质疑
- 认为用户方案有风险 → 说明风险但尊重决定
- 连续 2 轮未达成共识 → 暂停并明确分歧点

## 5. 验收确认

任务完成时额外确认：用户要求的验收标准是否全部满足？是否有需要用户手动确认的事项？

## 6. 给用户的输入建议（按需提示）

- Bug 报告：报错堆栈 + 复现步骤 + 预期行为
- 新功能：验收标准 + 参考设计 + 边界条件
- 重构：目标状态 + 不能动的模块 + 回滚条件
- 高风险操作走独立分支
